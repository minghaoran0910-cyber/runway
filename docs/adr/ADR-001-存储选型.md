# ADR-001 · 本地存储选型（SB-004 前置）

- 状态：Accepted（2026-10-10，随 SB-004 落地）
- 范围：SB-004 schema v1。后续卡不得援例改 schema（见任务卡授权声明）。

## 决策

- ORM：`drift`（类型安全 DAO + migration 框架，测试可用内存库）。
- 加密：`sqlcipher_flutter_libs`（SQLCipher 4，库文件整体加密，满足 PRD §4 本地优先/SQLCipher 加密）。
- 位置：`path_provider` 应用文档目录 `runway.db`，路径拼接用 `path`。
- 代码生成：`drift_dev` + `build_runner`（仅 dev）。

## 否决项

- `sqlite3_flutter_libs`：与 `sqlcipher_flutter_libs` 同属原生 SQLite 产物，同引会导致 Android `.so` 符号重复；后者已内含 SQLite 实现，故只引后者（对任务卡依赖清单的唯一偏差，见 REVIEW_REQUEST D1）。
- 分类色板：DESIGN_SYSTEM §4 要求未定色板前用中性瓦片 + 文字，本卡不引入分类颜色。
- 密钥管理：v1 用编译期开发密钥（`AppDb.devKey`，TODO 标记）；G4 前迁移到 Keychain/Keystore 随机密钥。真实账目数据永不入库（测试一律合成 fixtures）。

## schema v1（`Transactions`）

- `id` 自增主键；`amountFen` 金额（分，整数，>0）；`occurredAt` 时间戳；`category`（1–32 字符）；`note`（默认空）；`source`（默认 `manual`）。
- 回滚语义：v1 为首个基线版本，无线上存量数据；`onCreate` 建表，升级路径在后续版本以 `onUpgrade` 分步脚本落地。v1 回滚 = 删除库文件重建（`AppDb.resetDatabase` 已测试覆盖）。

## 备选（Rejected）

- `sqflite`：无需代码生成但 DAO 手写 SQL，类型安全弱，且 SQLCipher 需 `sqflite_sqlcipher` 分叉，维护面不如 drift + 官方 SQLCipher 组合。
- `hive`/`shared_preferences`：非关系模型，报表查询（G3 周报）扩展性差；且加密故事弱。
