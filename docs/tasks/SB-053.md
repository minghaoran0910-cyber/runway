# SB-053 · 首页「今日攒」空白卡（空壳 Card 泄漏）

> **状态**：待办（R149 见底自派，2026-10-23 15:4x）。按 2026-10-15 裁A 测试期冻结：施工/审查照常，**审过后不合入 main**，挂「已审待合」待 tag v0.1.0 批量落。

- **来源**：监工 R148 巡检（票359）视觉复核发现；SB-052 管线首次实拍首页时照出。属 **main 既有缺陷**，非 SB-052 引入，与 SB-051 动效工作面不重叠。
- **实证（开卡前 grep，2026-10-23 15:4x）**：
  - `app/lib/ui/today_saved_row.dart:55` → `return const SizedBox.shrink(key: Key('todaySavedEmpty'));` 命中条件：`todaySavedText(savedFen)` 为 null 且 `!isZeroDay(savedFen)`（即 **saved>0 但少于最小单价，文案换算不出**）。
  - `app/lib/ui/home_page.dart:321` → `Card(child: Padding(padding: EdgeInsets.all(RunwaySpacing.cardInner), child: TodaySavedRow(...)))`：**外层 Card 无条件渲染**，内层返回 shrink 后只剩空壳 + 内边距。
  - 用户可见后果：首页第三块出现一张**没有任何文字的空白卡**（浅/深主题均可复现）。
- **规范依据**：违 10-14 裁A「日载体常驻」的语义——常驻指载体行**有内容**，不是留一个空壳占位；也违 DESIGN_SYSTEM 的层级节奏（连续两卡之间出现零信息块）。
- **方案（二选一，实现者定，卡内不重复设计）**：
  1. 调用侧判定：`home_page.dart` 在渲染外层 Card 前用同一判据（`todaySavedText != null || isZeroDay(savedFen)`）决定是否出 Card；判据抽到 `today_saved_row.dart` 暴露为静态方法/布尔，避免两处口径漂移。
  2. 组件侧自决：`TodaySavedRow` 改为「有无内容」由调用方 `hasContent` 传入，`home_page` 据此包裹。
  - 硬约束：**零日档（saved<=0，含恰零/负结余）与可换算档（saved>0 且算得出）行为一字不变**，只消除「算不出但 saved>0」的空壳。
- **验收**：
  1. 新增回归测试：`saved>0` 且不足最小单价 → 首页该位置 **Card 不存在**（`find.byType(Card)` 计数或 Key 断言，二者择一写死）；同测锁死零日档仍有内容。
  2. 既有 `flutter test` 全绿（基线 504）+ `tool/ci.sh` 四闸绿 + `analyze` 零 warning + `dart format` 零改动。
  3. 不改文案（禁词表零新增）、不改 token/motion_spec、不加依赖（`pubspec.yaml` 依赖变更 = 0）。
  4. **视觉保真闸门**（本卡碰 `app/lib/ui/**`，强制）：提审单附模拟器实拍——空态（零日）与有数态各一帧，另加缺陷场景「saved>0 不足最小单价」修复前后对照一帧；REVIEW 必含独立「审美审计」小节（层级/间距节奏/圆角阴影 token/对比度/动效/AI 味/一致性）。缺图或缺小节直接 REQUEST_CHANGES。
  5. 文件数 ≤3（`app/lib` 1–2 + `app/test` 1），单文件 ≤400 行。
- **不做**：不顺手改首页其他区块、不动 SB-012/SB-051 工作面、不改 `docs/` 规范。
