# SB-050 · iconfont 矢量图标生产落地
- **来源**：浩然同批反馈④：「之前千叮咛万嘱咐多放图标，还给了阿里的矢量图标库，你一个都没用上。」
- **实测**：DESIGN_SYSTEM v1.0（10-08）规定 iconfont 线性图标 26 枚（demos/sprite.svg）+生产 svg pipeline；app/lib 现网零接入——欠账属实，v0.1 冻结未把该欠账显性化，监工侧失误入账。
- **方案**：接 flutter svg assets pipeline 进 26 枚实图标；类目/目标/实验/首页/我的逐页替换应用（系统级 Icons 保留除外）；商用授权逐一点名入册，存疑者换 Arco/Tabler 开源集。
- **验收**：五页生产图标 ≥12 处；Icons.* 残留白名单入册；授权清单入册；全量+三闸绿；golden 重刷。
