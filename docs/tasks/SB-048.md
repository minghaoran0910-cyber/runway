# SB-048 · 设目标表单控件修复
- **来源**：浩然同批反馈②：「设目标这个卡排版太乱；选择目标来个下拉框不行吗，想自己输入就给个自定义选项；日期为啥不是日历选择，还得手动输入？」
- **实测**：app 全域 grep showDatePicker/DropdownButton 零命中——日期确为文本手输，属实。
- **方案**：截止日期改 Flutter 原生 showDatePicker 日历选择（默认建议月末）；目标类型保留卡片并增设「自定义」卡点击展开行内输入；卡片间距按 token 整理。
- **验收**：建目标全程零数字键入（自定义名称除外）；排版 token 审计零裸值；全量+三闸绿。
