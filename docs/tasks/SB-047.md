# SB-047 · 账本（类目）页信息结构修复
- **来源**：浩然 2026-10-20 14:50 微信主session 反馈①：「目前账本这个页面我还是不懂（让我选 要花的/能省的/固定的），这个选项有啥意义？这个位置不是应该展示的是我消费的占比，类似饼状图，或者给些分析吗？」
- **判定**：角色三选是规则引擎输入**不可删**（预算线/冷静期只压"能省的"）；但页面无解释+占比分析被藏在"我的·关于"区=展示失败。
- **方案**：页首升本月类目消费占比可视化（复用 ring/percent 组件）；角色三选降为行内折叠+每角色一句人话解释（要花的=刚需不压；能省的=可优化空间，预算与冷静期压它；固定的=房租贷款，弹性之外）；未选行红点引导。
- **验收**：新用户不读说明能在 3 秒内明白"选它干嘛"；占比首屏可见；全量测试+三闸绿；golden 新帧。
