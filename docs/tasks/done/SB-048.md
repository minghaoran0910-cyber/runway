# SB-048 · 设目标表单控件修复
- **来源**：浩然同批反馈②：「设目标这个卡排版太乱；选择目标来个下拉框不行吗，想自己输入就给个自定义选项；日期为啥不是日历选择，还得手动输入？」
- **实测**：app 全域 grep showDatePicker/DropdownButton 零命中——日期确为文本手输，属实。
- **方案**：截止日期改 Flutter 原生 showDatePicker 日历选择（默认建议月末）；目标类型保留卡片并增设「自定义」卡点击展开行内输入；卡片间距按 token 整理。
- **验收**：建目标全程零数字键入（自定义名称除外）；排版 token 审计零裸值；全量+三闸绿。

## 14:50 补据（浩然"定一个目标"实拍，图存 runway-shots/2026-10-20-feedback/02_goal_editor_wall.jpg）
- 实拍确认三处硬伤：①一个 sheet 塞 8 类交互（名/额/期限/4 预设 chip/单价名/单价/常买键/中位数钮）——目标本质三件事（攒啥/多少/到哪天），参考单价与常买跟随（SB-020）是换算引擎，应折叠进「进阶」；②两处标签截断（"期限（日期 yyyy-MM-dd，…"与"常买键（类目｜备注，空=…"被裁）=布局 bug；③黑话外泄："常买键"是内部词，用户视角=「按你常买的价格自动定单价」。
- 非 bug 但要解释：5090 ¥16,499 是 PRD §2 阶梯档（奶茶→5090→余粮→自由基金→FIRE，goal_ladder.dart 在册），UI 没带出阶梯语境，看起来像乱入预设——chip 组归入换算区并加一句"攒够 X 件 Y"。
- 方案增补：表单重排=核心三项常显+「进阶（换算单价）」折叠；截断修复入验收（所有 label 无 ellipsis 或给 tooltip）；"常买键"改人话；预设 chips 仅在进阶区显示。
