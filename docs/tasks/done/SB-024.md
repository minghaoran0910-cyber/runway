## 第二轮 · 浩然裁定修订令（2026-10-12 16:57，推翻原推荐方向）
裁定原文："改，这些其他平台也得同步做哈"。执行口径：
1. **快捷指令升正式渠道**：采集主路径改为"推送式落盘"——iOS 快捷指令自动化捕获通知→写入 App 沙盒文件→App 读取解析（ADR 须写明此路不依赖"偷看"，苹果明文允许；被锁死的仅为主动读取路径）。邮件导入**降级为对账兜底**，手动记保留。
2. **导入矩阵四路 × 四平台同步设计**（产品级能力，非 iOS 专属）：
   - 通知捕获：iOS=快捷指令推送落盘 ／ Android=原生监听服务（SB-010 已落地）／ Mac=目录监听+账单投递 ／ Windows=目录监听（文件夹放置即采集）
   - 截图 OCR：iOS/Mac=系统 Vision（本地离线）／ Windows=本地 OCR 引擎选型（PaddleOCR/Tesseract 对比，不联网）
   - PDF 账单：支付宝/微信官方导出格式固定，四端统一解析层设计
   - Excel/CSV：微信加密 zip 流程单独评估，优先级最后；邮件保留但不再称主力
3. **隐私硬约束**：通知原文与账单文件解析入库后即删盘，只留结构化记录+hash 去重（沿用 SB-010 原则）。
4. **交付物 v2**：修订版路径裁定 + 四平台×四路能力矩阵表（每格：路径/依赖/置信度/坑）；PRD 采集层同步补矩阵条目；实现拆解预案（tag 后第一批卡）。v0.1 冻结线不变：本卡只动文档零运行时代码。
