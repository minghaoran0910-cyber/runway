# SB-011 · 账单文件导入（邮件附件 / 半自动口径）

- **目标**：从邮箱下载支付宝/微信账单（CSV）或分享文件到 App，解析合并入账，重复导入不重记。
- **引用条款**：PRD §3（iOS 快捷指令半自动 + 邮件账单导入 + 手动兜底；不得宣传"全自动"）；§5 隐私（导入文件内容处理后不留原文副本）。
- **授权声明**：允许 schema v6 迁移（import_batches 批次表，支持整批回滚删除；可回滚）。
- **涉及模块**：`app/lib/logic/`（CSV 解析 + 字段映射 + 去重合并算法）、`app/lib/ui/`（导入向导：选文件→预览→确认；失败行报告）、`app/lib/data/`（批次 DAO）、文档 `docs/ios-shortcuts.md`（快捷指令半自动说明，随卡交付）。
- **验收标准**：
  1. 支付宝/微信 CSV 账单合成 fixture 解析正确（含时区/金额单位/类目字段映射），失败行给出行号原因，不整体失败
  2. 去重：同一账单导入两次零重复（键=日期+金额+对方）；批次级可整体撤销
  3. 1 万行 CSV 解析+入库 <5s（合成数据，实测数字写进 progress.md）
  4. 原文件不留副本（导入缓存即删，单测断言）
  5. golden 四组：导入向导 Light/Dark × 预览/结果；四闸门全绿 + hygiene OK
- **预估文件**（≤10）：解析 2、DAO+迁移 2、向导 UI 2、文档 1、测试 4（合计 ≤10，测试文件可合并）
- **依赖变更**：无（csv 解析用 in-repo 轻量实现；若需包，先 ADR）
- **测试要求**：单测 ☑ / widget ☑ / golden ☑ / 对比度闸门 ☑
- **预估耗时**：4-5h
