# SB-004 · 三秒记一笔（含本地存储 schema v1）

- **目标**：用户打开 App 到记完一笔 ≤3 秒：数字键盘直输金额、默认类目一键选中、保存即回主屏。
- **授权声明**：本卡**显式授权**创建数据 schema v1（drift + SQLCipher），此为 DEV_WORKFLOW §2 禁区的卡内授权，后续卡不得援例改 schema。
- **引用条款**：PRD §2（极速记一笔≤3秒）、§4（本地优先/SQLCipher 加密/领域层不依赖 Flutter）、§5（隐私红线：真实账目数据不进仓库）；DESIGN_SYSTEM §2/§7（交互预算）。
- **涉及模块**：`app/lib/data/`（schema、DAO、加密库初始化）、`app/lib/logic/`（记账领域模型）、`app/lib/ui/`（记一笔页/数字键盘）、`app/lib/main.dart`。
- **验收标准**：
  1. 冷启动主屏 → 完成一笔（金额+类目+保存）实测 ≤3 秒（录屏留证，合成数据）
  2. schema v1：transactions 表（金额分、时间戳、类目、备注、来源），迁移可回滚，库文件 SQLCipher 加密
  3. 记录列表可查、可改、可删；重开 App 数据仍在
  4. 单测：领域层 CRUD；widget 测试：键盘输入→保存流；golden：记一笔页 Light/Dark
  5. `tool/ci.sh` 四闸门全绿 + hygiene OK；仓库内零真实账目数据
- **预估文件**（≤10）：schema/dao 2、领域模型 1、记一笔页 1、列表页 1、键盘组件 1、main.dart 1、测试 3（含 golden）
- **依赖变更**：drift、sqlite3_flutter_libs、sqlcipher_flutter_libs（须建 `docs/adr/ADR-001-存储选型.md` 后方可加）
- **测试要求**：单测 ☑ / widget ☑ / golden ☑（本组起强制四组）/ 对比度闸门 ☑
- **预估耗时**：4-6h
