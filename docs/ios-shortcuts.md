# iOS 快捷指令 · 账单半自动导入说明（SB-011）

> 口径：半自动（PRD §3）。从邮箱下载账单 → 分享到攒够 → 向导预览确认。
> 不得宣传"全自动"；IMAP 在线拉取留待 v0.2+ 迭代。

## 适用账单

- 支付宝：手机淘宝 App → 我的 → 账单 → … → 导出账单 → CSV（邮箱接收）。
- 微信支付：微信 → 我 → 服务 → 钱包 → 账单 → … → 导出账单 → CSV（邮箱接收）。

## 三步导入（约 1 分钟）

1. **取文件**：在 iPhone 邮箱 App 里打开账单邮件，把 CSV 附件存到"文件"（或直接分享）。
2. **进向导**：攒够 → 账单导入 → 粘贴 CSV 全文，或填缓存文件路径导入。
3. **预览确认**：核对"可入账 N 笔 · 失败 M 行"，失败行会给出列号级行号+原因；
   点"确认入账"。同一账单导两次不会重记（键=日期+金额+对方）；导错整批可"撤销本批"。

## 快捷指令（可选，一键直达）

1. 快捷指令 App → 新建 → 操作"获取文件"（选账单 CSV）→ 操作"打开 App"（攒够）。
2. 回到攒够账单导入页粘贴确认。快捷指令只做"搬运"，归类与去重仍在 App 内完成。

## 隐私

- 导入缓存原文读后即删，不留副本（PRD §5）。
- 失败行报告只在当屏展示，不写盘、不上报。
- 测试与演示一律用合成数据，真账单 CSV 不得提交到仓库。
