# DESIGN_SYSTEM ·「攒够 / Runway」设计语言 v2.1

> **单一真相源**，2026-10-08 定稿（23:24 全量审计修订）。整合 v1.0–v1.6 碎片修订为单文档（旧版存 `archive/`，已冻结不再更新）。
> 参照：`skills/awesome-design-md`（Apple/Linear/Cal/Stripe 等 50+ 设计系统索引）+ iconfont 真实图标集 + Apple《Designing Fluid Interfaces》。
> 目标：商业应用市场级品质的四端（iOS/Android/Win/Mac）Flutter App。"极简不单调、精致高级"必须落为**可判定规则**，不靠感觉。

## 1. 六条设计原则（一切争议的仲裁顺序从上到下）

1. **地面与浮起**：页面 = 柔和有色地面 + 悬浮圆角卡片；禁止通栏直角色块、禁止硬直线分界。
2. **形状语言只有三档**：主卡 r22 / 内容卡 r16 / 控件 r10、胶囊 r13。出现第四种形状 = 违规。
3. **层级靠留白与阴影，不靠线框**；hairline 仅用于列表行分隔。
4. **数字一等公民**：全局 tabular-nums；主数字（28/34pt）与其下副文案至少差 12pt，副标语永远不许压过主数字。
5. **动效解释因果**：只给"从哪来、到哪去"；过冲只属于手势动量；成就时刻是全 App 唯一允许表演的地方。
6. **装饰要么被看见要么不存在**：承载质感的装饰层透明度 ≥8%（低于此等于没做，v1.2 教训）；每屏高饱和强调色 ≤1 处。

## 2. Tokens（Light / Dark，落地映射 `tokens.dart`，CSS 镜像 `demos/tokens.css`）

### 2.1 色彩

| Token | Light | Dark | 用途 |
|---|---|---|---|
| ground | 渐变 168° `#F3F6F7 → #E8EEF1` | `#141616 → #101213` | 页面地面（禁纯白） |
| surface / surface-1 / surface-2 | #FFFFFF / #F7F8F8 / #EDEFEF | #141616 / #1C1F1F / #262A2A | 卡片三层材质 |
| ink | #383D3D | #ECEEEF | 正文主字 |
| ink-secondary-text | **#647576** | **#A6B2B4** | 正文级次要文字（≥4.5:1） |
| ink-secondary | #95A5A6 | #8B9698 | **仅装饰图形**，禁做小字 |
| accent | #5D8AA8 | #7FA6C4 | 色块/进度/大选中（≥22pt 或图形） |
| accent-strong | #3E6B86 | #8FB4D0 | 小字强调/链接（≥4.5:1） |
| gold | **#C08A3E** | #D8B27E | 成就/达标/家庭贡献 |
| gold-hi（深色卡内强调） | — | #EAD9B4 | 深色主卡内唯一暖强调 |
| danger | #B4552F | #D2704A | 超支/危险 |
| hairline | rgba(56,61,61,.08) | rgba(255,255,255,.09) | 行分隔 |

阴影 3 档：卡片 `0 1 2 .05 + 0 10 28 .09`；浮层 `0 4 16 .12`；深色主卡 `0 10 26 rgba(43,73,93,.26)`（彩色柔影，禁彩色硬影）。

### 2.2 字体与间距
- 家族：跟随系统（SF/PingFang/HarmonyOS/Noto/Segoe）；中文正文不加字距；26pt 以上负字距 -0.4～-0.6px。
- 字号阶梯：9.5 / 11 / 12 / 13 / 15 / 17 / 20 / 26 / 28 / 34；行高 1.4–1.6；字重只用 400/500/600/700/800。**demo（v12 冻结基线）存在 10/10.5/11.5/12.5/14.5/16/21/22/27 过渡值，Flutter 落地一律就近收敛到阶梯；G1 起出现阶梯外字号 = Golden 红。**
- 间距 4/8 网格：页边距 16（demo 现值 18 为过渡值）、卡内 16、区块间 24、分区头 margin `24 上 / 12 下`；负 margin 压卡（浮层感）18–40。

### 2.3 对比度闸门（CI 强制）
一切文字级 token 组合 ≥4.5:1；≥22pt 大字 ≥3:1；装饰图形不设限但不得承载信息。

## 3. Hero 主卡规范（2026 主流做法，替代早期"深色通栏 band"）

- 渐变：`linear-gradient(142°, #25404F, #3E6B86 58%, #557F99)`；radius 22；`border-top:1px rgba(255,255,255,.16)` 内高光。
- 右上 230px 径向光晕（radial-gradient 圆，18% 冷白蓝）——**禁止 CSS `filter:drop-shadow` 做光晕**（SVG 包围盒方形伪影教训）。
- 内部四层文字层级：12.5px/74% 白（标题）→ 28px/100% 白（主数字）→ 12px/62% 白（副数据）→ 暖金 #EAD9B4 **仅一处**。
- 页面组成只有四种：ground 纹理层（点阵 mask 顶部淡出）/ hero 主卡 / 内容卡 / 悬浮 TabBar+FAB。

## 4. 图标系统

- 风格：iconfont 线性图标（24 网格、描边 1.7、圆头、currentColor、单色）。
- **UI 层禁止 emoji 做图标**（emoji 仅限文案正文的趣味单位）；行内图标必须 `inline-block` + 基线对齐（教训：`.ic{display:block}` 导致"11 杯🧋"断裂换行）。
- IconTile：34px 圆角 10 浅底内描边，图标 19px；达标态用 gold 瓦片；Tab 未选中 45% 透明、选中 accent-strong。
- 资产：`demos/sprite.svg`（26 枚实抓 iconfont 源）为 CSS 真相源；生产走 svg assets pipeline；**商用前逐一确认作者授权，或委托原创**（备选开源集：Arco Design Icon / Tabler Icons）。
- 同屏图标同一网格与视觉重量；分类未定色板前用中性瓦片+文字（色板走 ADR）。

## 5. 图表规范

- 折线：Catmull-Rom→三次贝塞尔平滑，禁硬折；面积填充 accent 22%→0 渐变；末端点 halo。
- **端点 marker 距 svg 边界 ≥8px**（path 起点 x≥2、终点 x≤宽-r-4；教训：r=4 圆点贴边被裁半）。
- 进度环：96px（r40）、线宽 9、渐变描边（亮灰蓝→深）、圆头；环扫过与数字 count-up 共用同一进度函数。
- 禁 3D、禁饼图轰炸；sparkline 高 ≤56px。

## 6. 动效体系（MotionSpec 统一封装，禁散落参数）

| 场景 | 时长/物理 | 表现 |
|---|---|---|
| 按压反馈 | 120–160ms | scale .96，pointer-down 即响应 |
| 状态变化/数字滚动 | 220–320ms（滚动≤600） | emphasized-decelerate `cubic-bezier(.2,0,.1,1)` |
| 页面转场 | 320–400ms | shared-axis Z + 轻视差，四端同一语言 |
| Sheet/弹层 | 进 280 / 出 220ms | spring damping .8 / response .3，跟手拖拽 |
| 列表入场 | stagger 80ms/行（demo reel 压缩为 ~130ms，实现按 80ms） | 上浮 14–16px，仅首屏 |
| FAB/成就卡 | easeOutBack c1=1.70158 | **唯一允许过冲**；成就 900–1200ms+粒子≤12 颗 |

- spring 默认全局 damping 1.0（临界阻尼不过冲）；任何动画可从当前呈现值被打断重定向，禁锁输入。
- `reduce-motion` 开启：全部转场降级 80ms fade。
- 触觉：记一笔 .light｜达标 .medium+notification.success｜橡皮筋 .rigid｜撤销 .heavy；默认无音效。
- 骨架/加载 shimmer ≤300ms 后出现；动效不得阻塞输入。

## 7. 交互预算与文案基调

- 记一笔 ≤3 秒/3 步；日报一屏内、30 秒读完；推送 ≤3 条/日。
- 纠偏一次点击即固化规则；分类不明问一句"回个数字"。
- 全部换算用**得到框架**（"省出了什么"），禁亏欠框架（"又花掉几杯奶茶"）；大额提示只陈述不劝阻。

## 8. 验收 Golden Gate（不过即 CI 红）

1. 每屏 golden 4 组（Light/Dark × 移动/桌面），像素 diff 超阈值打回；基线变更需 PR 说明+监工逐张目审（防 AI 改基线骗测）。
2. 走查清单：直角通栏？/ 第四种圆角？/ 装饰不可感知（<8%）？/ 强调色>1？/ 图文同行断裂？/ **贴边裁切逐元素查**（marker、stroke 端头、阴影、渐变边缘）/ 对比度闸门 / 深色卡层级压序。
3. 视觉自检按**独立颗粒度**逐项提问（图表端点一题、图标瓦片一题、行内图标一题），禁笼统合并问（教训：合并问法漏检）。
4. 动效验收必须用 24fps reel 视频，静图不作动效结论；演示物料一律标注"示例数据"（禁编造指标当真数）。
