## 角色契约（本项目的宪法）

- **浩然**：决策者。批准范围、命名、设计变更、数据模型变更；只看飞书报告与决策点。
- **老油条（监工）**：制定任务卡 → 逐 diff 审计 → 给通过/返工判决 → 汇总周报。**不写业务代码**。
- **opencode（施工方）**：按任务卡写码与测试；**永远不许自行 merge、不许改设计 token、不许加新依赖、不许超出任务卡文件数上限**。

## 开工顺序（阶段闸门，未过闸门不得进入下一阶段）

1. **G0 规范批准**：浩然批准本套文档（含命名与 Flutter 选型）。
2. **G1 骨架**：仓库初始化 + 设计 token 落地 + CI 四闸门跑通（空工程也要绿）。
3. **G2 核心闭环**：三秒记一笔 → 分类（规则引擎）→ 首页目标看板。
4. **G3 钩子层**：目标阶梯/成就卡/安全垫/周报。
5. **G4 采集与自动化**：Android 通知监听、邮件账单导入。
6. **G5 打磨与冻结**：动效全量走查、性能预算达标 → v0.1 tag。
